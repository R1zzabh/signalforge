# Viva notes

RPA automates repeatable digital work; UiPath is useful for Excel, HTTP, Outlook, retries, and branching. A SOC monitors and responds to security events. SIEM aggregates events; SOAR automates response. An IOC is an observable indicator such as an IP, domain, or hash. MITRE ATT&CK is a behavior knowledge base. Deterministic rules make score and severity explainable and testable; AI adds readable context but cannot override controls. If an API fails, the pipeline records the unavailable provider and continues with available evidence. Human-in-the-loop protects critical actions. FastAPI is typed and lightweight; SQLite is portable for an academic prototype. Enterprise deployment would add auth, queues, Postgres, secrets management, provider clients, and SIEM connectors.
